# Specifications

## Introduction

Eurydice is a project that aims to help people with attention issues.

## Features

We have a couple of main features that our project will have regardless of potential futur modifications.

### Project management

The main feature of our project is Project management.

#### Tasks

A project is composed of tasks. The sum of the tasks rewards gives the total reward amount for a project, with a bonus to celebrate a project completion.

To create a task, the user has to do the following :

- Give the task a name,
- Give the task a deadline,
- Select in which of the four stats (Health, Knowledge, Creativity, Wealth) the task is relevant,
- On a 1 to 10 scale, chose the difficulty of the task,
- On a 1 to 10 scale, estimate the time lenght of the task.

Tasks can also be blocked by other tasks, to create a workflow.

#### Calendar

All projects have a calendar in which it is possible to view all the tasks linked to this project, to provide a visual feedback.

#### Statistics

Each project has a Statistics page, containing the following :

- The total time spent on this project,
- The weekly/monthly/yearly breakdown of tasks completed on this project,
- The number of days a task has been completed in this project,
- The daily average time spent working on this project,
- The best streak of completed tasks in this project.

The statistics are collected through a timer that is manually launched by the user upon starting to work on a task (cf Time Management).

### Daily Quests

We will have a Daily Quests system to encourage users to get their tasks done and add novelty to their day to day life. The quests can range from getting a fixed amount of xp in a day (meaning completing a few tasks), doing a healthy habit, such as drinking water 5 times a day, or little adventures, like going outside and seeing a dog.

### Guilds

The social aspect is an important part of the process of staying motivated, because having friend to hold you acountable can motivate a lot.

The guilds can host up to five users maximum, to keep the groups small and friendly. The objective is to form a guild with your friends without being overwhelmed by competing with the whole user base.

Guilds allow the users to see each others statistics. They also make the creation of Guild Quests possible. Guild Quests are quests that are assigned to each guild user. Guild Quests reward the users that complete them and also the guild if all users complete them, allowing the guild to level up.

Guilds are optional.

### Time management

Tracking the passage of time can be a motivator too.

We offer different types of clocks, timers, countdowns, etc, for the user to track the time spent on a task, or the time left to spend.
